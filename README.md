# tinkrkit.dev

Free, fast, browser-based toolkit. No login. No backend. No nonsense.

## Dev

```bash
./restart.sh        # clean restart (clears .next cache)
./restart.sh --hard # also clears node_modules/.cache
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 14 (App Router)
- Tailwind CSS + shadcn/ui
- All tool logic runs in the browser — zero API calls
